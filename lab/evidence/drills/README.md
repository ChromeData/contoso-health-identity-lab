**No drill has been run yet.** The rows below are an empty template. Add a
row only for a drill that actually happened, with values you observed. Leave
a cell blank (or write "not checked") rather than estimating.

**This file is public.** Record account short names (`bg-admin-01`), key
labels, times and ticket numbers only. No IP addresses, object IDs, tenant
domains or screenshots; those stay in the ticket or the gitignored
`../out/` folder.
